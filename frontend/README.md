# TrapeGen 模型工作台

在项目根目录运行。Python 依赖由根目录的 `setup.py` 管理，浏览器依赖由本目录的 `package.json` 和锁文件管理。

```bash
source .venv/bin/activate
uv pip install -e .
(cd frontend && npm ci && npm run build)
python frontend/server.py --port 8765
```

打开 http://127.0.0.1:8765 。页面默认显示 `xiong.stl`，单位 cm，黄线 69 mm，蓝线 87 mm，偏移 7.5 mm，角度 53°。

- 左键旋转，右键平移，滚轮缩放。视窗下方可切换正视、侧视、俯视与适应窗口。
- 点击「打开 STL」或将文件拖入视窗，可一次添加多个文件。顶栏中央的下三角打开暂存模型选择器，支持点击、左右方向键和触屏横滑。每个条目保留原始 STL 和首次载入时生成的缩略图。同名条目在选择器中加序号，下载使用原始文件名。
- 暂存卡片右下角的「×」打开删除确认。确认后清除该条目的页面缓存和草稿。删除当前条目后切换到相邻模型，删除最后一条后回到空工作台。删除前已发起的导出会按点击时的参数继续完成。
- 模型切换时保存并恢复 STL 单位、参考线、梯形参数、搜索条带、合并选项、摆正姿态和装配特征草稿，自定义轮廓也随条目保存。切换后以目标模型适应窗口，并重新生成截面和预览。非激活模型释放解析网格和 Worker。暂存在当前页面有效，刷新页面会重新打开默认小熊。
- 顶栏「模型摆正」支持绕固定的加工 X / Y / Z 轴正向或负向旋转，按右手规则以原始包围盒中心为支点。每次默认旋转 90°，步长可手动输入。相机维持当前视角、平移和缩放，点击「重置姿态」恢复摆正前的模型。黄、蓝线高度和 Z 条带数值仍按摆正后的局部毫米坐标解释，旋转后可以按新的截面位置调整。
- 「裁剪预览」标题可向上收起参数栏。收起后，视窗编辑工具、裁剪参考面、网格和坐标轴随之隐藏。两个参数栏都收起时，主视窗显示当前姿态下的完整模型。再次展开可继续调整原有参数。
- 底边左右端可分别在自动取点基础上输入局部 X 偏移，负值向左，正值向右。「恢复自动底边」将两端偏移归零。调整一端时另一端和斜边角度保持原值，上底同步重算。端点交叉、重合或上底宽度不为正时会提示原因并停用导出。预览、装配切面和导出共用 `ab_x_offsets_mm`。
- 点击参数数值可直接输入，也可用旁边的「−」「+」微调。向上偏移、斜边角度和不透明度滑块的「范围」可设置最小值、最大值及步长。应用范围保留当前值，微调使用原有步距。导出时向上偏移须在 5–10 mm、斜边角度须在 52–55°。A/B 偏移和滑块范围随模型草稿保存。
- 参数面板支持键盘和滑块。视窗工具栏的「移黄面」「移蓝面」可沿 Y 拖动参考面，「转斜面」沿 Z 旋转手柄并同时更新两个斜面。「查看」收起手柄。待裁剪区域用半透明深红色显示，默认不透明度为 20%，可调整为 0–100%。
- 勾选「A/B 前后搜索条带」后，用数字输入或滑块设置局部 Z 下限和上限，单位为 mm。小熊的初始条带是 −12 至 12 mm。在俯视图可查看红线截面的灰色外轮廓、青绿色条带及参与 A/B 搜索的轮廓线段。A、B 标在实际找到的 XZ 坐标上，参数栏显示坐标数值。梯形和裁切面仍沿 Z 贯穿整个部件。收起面板或进入对比时隐藏条带辅助图层。
- 右上角小窗显示裁剪结果，装配特征就绪时显示带实体凸柱或带孔口、孔壁和孔底的加工结果。悬停右下角「对比」时，同一个结果移到主视窗，小窗隐藏。键盘聚焦和触屏按住也可对比。切面刷新期间，小窗与对比先展示当前裁剪基体。
- 「装配特征」默认关闭。展开后，主视窗底部的选择器显示六种预设的三维缩略图。可点击卡片、用两侧按钮、聚焦后用左右方向键，或通过滚轮和触屏横滑切换。选中卡片停在中央，首尾停止。蓝色描边显示实际切面及内孔，绿色体积为凸柱，红色体积为预定移除区域。可用「俯视」检查轮廓和偏移。
- 尺寸、柱高、孔深和 XZ 偏移均用局部毫米。圆形填直径，三角形和六边形填边长，自定义轮廓填旋转前包围盒的最大边长。旋转按 +Y 右手规则，偏移从切面最大材料区域的面积中心起算。凸柱沿 +Y，盲孔沿 −Y。
- 「装配特征」面板中的「上传 JSON」接受 `[[0,0],[4,0],[4,1],[1,1],[1,3],[0,3]]` 或包含 `profile_xz` 的对象。沿轮廓顺序给出 3–128 个点，可使用凹多边形。导入后选择器显示并选中自定义三维缩略图，参数栏可切换凸柱或盲孔。
- 「导出裁剪 STL」提交原始文件与点击当下的姿态和裁剪参数。后端生成、验收成品并转回原 STL 的坐标系和单位。摆正模型、拖动参数与换视角都在浏览器完成。「下载原始 STL」保存原始字节。

## 实现

- `src/viewer.js` 管理 Three.js 场景、STL 解析、OrbitControls 和 TransformControls。参考 Three.js Editor 的视窗交互，拖动编辑手柄时暂停相机操作。
- `src/preview.js` 更新少量辅助面的顶点与着色器参数。场景与输入更新合并到同一个动画帧。
- `src/caps.js` 使用 WebGL 模板缓冲计算各裁剪面的截面遮罩。封面贴合闭合 STL 的实际截面，并保留截面内的空洞。主视窗和小窗复用同一组遮罩，旋转视角时直接重新绘制封面。
- `src/profile.js` 使用局部毫米计算梯形。`src/section.js` 基于三角形和平面求交构造轮廓，嵌套孔洞作为同一截面的内部轮廓处理。启用条带时，截面外轮廓的线段在条带边界插值截断，A、B 取截断后路径的 X 极值，孤立接触点不参与搜索。`src/search-band.js` 绘制搜索范围、轮廓和 A/B 标记。移动条带或调整斜边角度时复用当前截面。截面会话缓存已计算的高度，并只接收当前工作网格与截面的 Worker 结果。
- 样件的 51 组截面覆盖黄线 69 mm、偏移 5–10 mm、步长 0.1 mm。它们来自后端合并外壳后的有效网格，使用 SHA-256 与原文件核对，且仅用于原始姿态。首次启用条带时，浏览器加载预计算外轮廓。其他姿态、高度与自定义模型使用 Worker。轮廓相交、存在多个独立轮廓或截面无效时，页面保留参考平面并显示原因。需要合并外壳且只有原始截面时，页面标记近似预览。浏览器截面针对 STLLoader 的浮点网格计算，边界仍由后端校验。
- `src/model-pose.js` 计算供工作网格和 `/api/clip` 共用的姿态。提交的矩阵为 4×4 按行排列，作用于已换算成毫米的原始坐标，平移也以毫米计。姿态变化时 `src/app.js` 从原始网格重建工作网格，更新包围盒和截面会话，同时保留局部裁剪参数。
- `src/connector-surface.js` 在装配栏展开时用当前模型和裁剪参数请求 `/api/connector-surface`。内置小熊直接用样件 ID，自定义 STL 首次读取切面时上传原件。模型、姿态或裁剪参数改变时，清除旧切面并合并快速输入，只采纳当前请求的响应。
- `src/connector.js` 按接口规则定位特征并检查投影与切面轮廓、内孔的位置关系。`src/connector-preview.js` 绘制实际切面和半透明加工体，并为小窗和「对比」共用的结果生成带开口的顶面、特征壁和端面。调整特征参数直接更新本地预览，后端导出负责检查材料支撑和盲孔深度。装配栏展开时按当前特征导出，收起后恢复常规裁剪。
- `src/carousel-selector.js` 提供独立的 `CarouselSelector`。构造参数包含 `items`、`selectedIndex`、`onChange(index, item)`、`label` 和可选的 `style`。栏目接受 `{ id, name, thumbnail }` 或 `{ id, name, icon }`，`thumbnail` 为图片 URL，`icon` 为文字或 DOM 节点。外部可通过 `setItems(items, index)` 和 `setSelectedIndex(index)` 同步选择，通过 `style` 设置 `item-width`、`gap`、`accent`、`duration`、`easing` 等样式变量。`src/connector-thumbnail.js` 使用同一套装配轮廓和 Three.js 网格绘制缩略图。
- `src/model-picker.js` 用独立条目 ID 管理暂存模型。`src/thumbnail-studio.js` 为模型与装配缩略图共用一套离屏 Three.js 渲染器。与默认小熊字节一致的副本沿用样件初始参数，编辑状态分别保存。
- `src/model-api.js` 按条目复用上传 ID。服务器缓存过期时，使用该条目的原始文件重新上传，并用原请求参数重试。导出完成后，文件名和状态归属点击导出时的条目，切换模型期间可继续编辑。
- `src/app.js` 管理文件、参数、预览状态及导出。启用条带后，导出请求携带点击瞬间的 `ab_z_range_mm`。`server.py` 提供本机页面与上传、裁剪 API。服务端按文件内容复用最近八个已提交文件，退出时清理。

重新生成小熊截面表并运行截面测试。

```bash
source .venv/bin/activate
python frontend/tools/build_sample_sections.py
node --test frontend/tests/*.test.js
```

## 小熊验证结果

下表的性能数据来自新增透明叠层和双视图之前的实时预览版本。

测试环境为 Windows 无头 Chrome 158.0.8127.37，经 ANGLE / Direct3D 11 使用 Intel Arc 130T GPU。后端运行于同机 WSL2（Ubuntu 22.04、Intel Core Ultra 5 225H）。浏览器视口 1254 × 800，画布 934 × 728，DPR 1。

| 指标 | 结果 |
| --- | --- |
| 连续更新角度时的浏览器帧间隔，120 帧 | 中位数 6.1 ms，P95 12.2 ms，最大 18.3 ms |
| 小熊预计算范围内的偏移更新，12 次 | 从输入事件到新预览提交绘制，中位数 6.2 ms，P95 6.6 ms |
| 后端裁剪、网格校验、导出及回读，模型已缓存 | 4.98 s（7.5 mm / 53°），3.07 s（8.4 mm / 55°） |
| 同一测试服务的首次导出，模型需准备 | 8.35 s（7.5 mm / 53°） |

帧间隔来自持续更新角度时的 `requestAnimationFrame` 时间戳。偏移计时覆盖查表、视图更新和绘制提交。后端时间来自 `Server-Timing`，包含文件生成和回读，上传、下载时间另计。

| 偏移 / 角度 | 浏览器显示的 A、B（X，mm） | 回读结果顶边的 X 范围（mm） | STL 三角面 |
| --- | --- | --- | ---: |
| 7.5 mm / 53° | −37.8453 / 37.8463 | −29.93297 / 29.93393 | 270,364 |
| 8.4 mm / 55° | −37.6769 / 37.6779 | −30.95493 / 30.95589 | 270,684 |

两份 STL 回读后均闭合。浏览器显示的 A、B 与 Python 截面相符，导出顶边与 Python 算出的 C、D 顶点误差小于 0.0001 mm。测试通过 Chrome DevTools 协议记录网络。拖动、切换视角、打开自定义 STL 和拖放文件期间没有上传或裁剪请求，两次明确导出分别产生一次上传和一次裁剪。导出期间修改滑块，服务器仍收到点击时的参数。通过人为延迟 Worker 响应验证了快速调参和切换模型。双轮廓样件显示歧义提示，自定义原始 STL 下载逐字节一致。

## 模型摆正验证

在 Chrome 158 上用一个以 cm 存储、偏离原点的非对称闭合 STL 测试。绕 Z 轴旋转 +90° 后，局部截面 A/B 的 X 从 70 / 141 mm 变为 85 / 135 mm，重置后恢复。摆正前与重置后的主视窗模型截图逐像素相同。旋转时截面 Worker 使用新的工作网格，小熊重置后恢复使用预计算截面。

两次导出上传的原始 STL 哈希相同。第一次点击导出后立即重置，裁剪请求仍携带点击时的 +90° 变换。按原始坐标回读，旋转后的裁剪上限对应 X = 11.6 cm，重置后对应 Y = 3.6 cm。两份成品均闭合，并在各自的加工坐标系中达到预览给出的上底位置。

## 装配特征验证

在 Windows 无头 Chrome 158.0.8127.37 使用小熊测试。修改尺寸、深度、角度、偏移和导入自定义轮廓期间，网络记录无切面或裁剪请求。将蓝线改为 86 mm 并延迟响应，再绕 Y 旋转 +90°、改为 86.5 mm，界面继续等候并采用最新姿态和高度的切面。裁剪请求使用同一姿态矩阵。

| 导出场景 | 局部 Y 端面（mm） | 回读结果 |
| --- | ---: | --- |
| 直径 8 mm、柱高 6 mm 的圆柱 | 93 | 柱顶轮廓与中心符合预览 |
| 边长 5 mm、孔深 4 mm 的六角盲孔 | 83 | 孔底轮廓与中心符合预览 |
| 模型旋转后，柱高 5 mm 的自定义凹轮廓 | 91.5 | 柱顶轮廓与中心符合预览，增量 120 mm³ |

四份 STL 均按项目读入规则回读为闭合实体。特征端面轮廓与预览在 0.00005 mm 容差内一致。

结果视图在同一 Chrome 版本复核。小熊的圆柱和六角盲孔同步显示于小窗与悬停对比，俯视可见孔口，斜视可见孔壁。小窗可完整显示超出原模型高度的 90 mm 凸柱。另用平顶长方体验证蓝切面与原顶面重合时孔口仍正确显示。切面刷新时回到当前裁剪基体，收到最新结果后恢复特征。改特征参数和切换对比期间无上传或裁剪请求。

选择器在 Chrome 158 验证了六张预设缩略图、自定义凹轮廓的凸柱与盲孔缩略图、快速反向连按和首尾限位。390 px 视窗下，选中卡片仍对齐固定中央框，触屏横滑可切换。启用系统减动效后立即切换。选择预设或导入轮廓期间，网络记录只有展开装配栏时请求的蓝切面。

## 多模型暂存验证

在 Chrome 158 中用「打开 STL」和拖放分别添加两个同名小熊副本。第二份仅改动 STL 文件头，用于核对上传 ID 归属。两个条目分别保存相反的 Y 轴姿态、参考线、梯形参数、A/B 范围和装配设置，反复切换后均正确恢复。另在窄屏验证触屏横滑，以及延迟读入的自定义 JSON 写回发起读入的条目。

保留一个迟到的蓝切面响应并快速切换条目后，当前预览仍对应选中模型。真实淘汰后端八条上传缓存后发起导出，导出中切换到另一副本和默认小熊。重传使用发起导出的条目原件，下载名仍为 `copy-clipped.stl`。按点击时的姿态回读，成品闭合，自定义柱顶 Y 为 89.4 mm，面积为 18.375 mm²。

在 Chrome 158 验证删除确认和取消、同名条目分别删除、删除当前条目后恢复相邻草稿，以及删除最后一条后重新载入。删除已摆正的当前模型时，其截面 Worker 随之释放。删除正在导出的条目后，已发起的下载正常完成。

## 底边端点调节验证

在 Chrome 158 使用带左右凸耳的闭合测试件，启用 Z 条带并设斜边角度为 53°。只扩左端时，预览 A/B 的 X 为 −45 / 30 mm，导出保留左侧凸耳。只扩右端时，预览 A/B 的 X 为 −30 / 45 mm，导出保留右侧凸耳。装配切面和导出请求使用相同的端点偏移。两份 STL 回读均闭合，切面和外轮廓与预览裁剪规则一致。

端点交叉、重合和上底宽度不为正时，页面显示对应提示并拦截导出。已验证手动输入、微调、自动归零、滑块范围与当前值分离，以及切换模型后恢复各自的端点偏移和滑块范围。
