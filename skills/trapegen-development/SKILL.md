# TrapeGen 开发规则

1. 使用 `uv` 管理项目环境。安装任何包或运行代码前，在项目根目录执行 `source .venv/bin/activate` 激活生产环境，并在同一个 shell 中执行后续命令。
2. 将项目使用的所有第三方包记录在 `setup.py` 的依赖配置中。迁移到已激活的目标环境后，在项目根目录执行 `uv pip install -e .`，安装项目及其依赖。
3. **前后端分离。** 后端任务负责实现模型裁剪、结果验证和导出，并提供供前端调用的接口，明确输入、输出、单位、坐标系和错误行为。后端任务的交付范围止于接口，无需实现前端页面或交互。

   前端任务限于界面、交互、浏览器预览和调用现有后端接口。最终裁剪 STL 由后端生成。前端任务不得修改后端代码或接口约定。代码归属按职责判断，例如 `frontend/server.py` 虽在 `frontend/` 下，仍属于后端。

   当前端需求与后端接口或裁剪规则冲突，或现有接口无法满足需求时，暂停涉及冲突的改动，向用户说明冲突点、可选方案及其影响，由用户决定调整哪一侧及接口约定后再继续。
