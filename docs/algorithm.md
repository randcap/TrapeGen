# 算法与数值约定

1. Trimesh 读取 STL 并合并完全重合的顶点，以恢复共享边。以边使用次数、面片环绕、非流形顶点、三角面片退化和正体积条件验证拓扑。Manifold3D 使用双精度坐标表示实体。
2. Open CASCADE 按 IGES 单位转入毫米，然后与 STL 一样应用原始毫米坐标到局部毫米坐标的刚体变换。检查转换后参考边的 Y 方向范围和非零 X 跨度。有多个候选边时按提取后的零起始索引显式选择。
3. 计算 `y_red = y_yellow + offset_mm`。对原始三角面做 `Y = y_red` 平面求交，按 XZ 线段连接关系构造截面轮廓。嵌套奇数层轮廓作为孔洞处理。对所选外轮廓取 X 左右极值得到 A、B。
4. 计算 `h = y_blue - y_red` 和 `inset = h / tan(angle)`。C 从 A 向右缩进，D 从 B 向左缩进。按 A、B、D、C 的顺序建立逆时针梯形，检查上底宽度和多边形有效性。
5. 构造下方保留矩形，使其覆盖红线以下的原始部件 XY 包围盒投影。按逆时针顺序将矩形和梯形外边界拼成一个二维保留多边形。Trimesh 和 Earcut 对梯形和保留多边形分别三角剖分，从 `z_min - margin` 拉伸到 `z_max + margin`。
6. 对原始实体与保留实体做一次求交，得到最终完整部件。独立装配区域需要时另算一次原始实体与梯形实体的交集。
7. 在局部毫米下复核网格拓扑和体积。对红线以上三角形顶点和与红平面的交点检查梯形侧边不等式，同时检查蓝线高度上限。分别用红线半空间对输入与输出实体裁切，比对红线以下体积。最终结果通过和保留实体的求交得到，红线以下的体积差用来检验保留材料是否减少。
8. 将结果逆变换并恢复原 STL 的单位。经二进制 STL 的 Float32 序列化后，再导入并重复几何检查。验收 JSON 记录实际使用的精度阈值，序列化检查包含随原坐标量级变化的舍入裕量。

## 拓扑与自相交检查的范围

- 检查每条边的入射面数量以及每个顶点的面扇连通性，统计边连通的面片分量。验收同时要求 Manifold 能接收导出的网格。
- 多个正体积外壳通过比较各壳体积之和与实体并集体积来检测有体积的外壳重叠。修补需要显式启用。具有反向内腔壳体的模型保留其符号拓扑，报告会标记没有独立外壳重叠检测。
- Manifold 的拓扑状态和体积核对无法代替对全部三角形的独立自相交检测。报告的 `self_intersection.status` 明确记录核查范围。这一版也没有做逐点表面距离审计。
- 正常裁剪路径保留网格精度，生成流程不执行平滑、简化、体素化或全局重网格化。
