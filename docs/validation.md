# 验收报告

## 环境

生产环境 `.venv` 使用 CPython 3.10.12。验证版本为 NumPy 2.2.6、SciPy 1.15.3、Trimesh 4.12.2、Shapely 2.1.2、Earcut 2.0.0、Manifold3D 3.4.1 和 Matplotlib 3.10.8。采用本地缓存中的 Python 3.10 几何库 wheel，原空 Python 3.13 环境备份于 `.venv-py313-backup`。

Open CASCADE 依赖已写入 `setup.py`，但当前沙箱访问 PyPI 时连接被拒绝。`uv pip check` 唯一缺失项是 `cadquery-ocp-novtk==7.8.1.1`。现有环境可运行合成测试及 Type 110 小熊演示。带有 Open CASCADE wheel 的环境可用 `uv pip install -e .` 完成依赖安装和运行相应测试。

## 合成测试

在项目根目录激活生产环境后运行测试。

```bash
source .venv/bin/activate
python -m unittest discover -s tests -v
```

共 17 个测试，16 通过，1 个因 Open CASCADE 未安装而跳过。测试覆盖以下项目。

- 长方体截面、四顶点、拉伸范围、装配区及最终体积的解析比较，包含 3 个偏移与 3 个角度的九种组合。
- 球体、椭球、非对称突起、内孔、多轮廓、经过顶点与边的截面，以及包围盒内部的空截面。
- 红蓝线位置、上底非正、无效参数、开边、非流形顶点、退化三角形和显式外壳并集。
- 不同单位的 STL 和 Type 110 IGES 加刚体变换的完整流程、参考线选择及异常、导出后二进制 STL 再读取。
- CLI、二维与三维渲染、滑块和 Apply 事件。图形事件使用 Matplotlib Agg 画布模拟，当前环境未进行桌面窗口交互测试。

输入取仓库中的 `data/stl/xiong.stl`，演示将坐标解释为 cm。蓝线 `data/igs/xiong-blue-demo.igs` 是临时生成的毫米单位 Type 110 水平线，经 `line` 读取器接入。黄线定位在两眼中心附近。当前验证覆盖已有小熊 STL 与合成 IGES 线，不构成对客户 IGES 文件或 Open CASCADE 后端的验收。

自相交的独立逐三角形检测未执行。验收结果包含实体后端接受、拓扑检查、壳体重叠量、上下区域体积及裁剪范围检查。
